\begin{abstract}
This document specifies a Python research pipeline that (i)~simulates hippocampal and afferent single-unit activity during open-field navigation, (ii)~records it through a Neuropixels-like probe with sorting degradation, and (iii)~decodes behavioral latent variables from \emph{causal} population spike counts.
The neural model uses a maximally hippocampal RatInABox population table (CA1--CA3, DG, subiculum, MEC) with anatomically correct probe contact mapping, post-hoc theta / ripple / sparsity / recurrent / inhibitory overlays, and trisynaptic / entorhinal feedforward coupling (MEC$\to$DG$\to$CA3$\to$CA1, INT$\to$CA1).
Hyperparameter search over decoder models, causal integration windows, and optional manifold features is performed automatically on \textbf{sorted} (Neuropixels / Open~Ephys / Kilosort-like) spikes; the selected deployable configuration is then replayed in a closed-loop causal setting.
Ground-truth spikes remain an optional oracle diagnostic and are never used to select realtime models.
We document RatInABox populations, dynamics overlays, feedforward equations, probe--region geometry, deployment vs.\ oracle spike sources, causal decoding, decoder models, and manifold feature modes with explicit mathematics and default parameters.
\end{abstract}

\section{Introduction and scientific framing}
% ============================================================

The simulator knows the true behavioral state.
The decoder observes only spike times.
Two spike sources exist, with distinct roles:
\begin{description}[leftmargin=*]
  \item[\textbf{Sorted spikes}] Neuropixels-like acquisition degradation and Open~Ephys / Kilosort-like re-extraction (misses, jitter, contamination, amplitude drift, collisions, noise, unit-quality variability).
  This is the \emph{only} valid source for deployable model selection and closed-loop realtime replay.
  \item[\textbf{Ground-truth spikes}] Ideal Poisson spikes from the rate model.
  Optional \emph{oracle / non-deployable} diagnostic that upper-bounds information before recording degradation.
\end{description}
Searching causal integration windows asks how much recent neural history each target requires.
Searching decoder families asks which estimator best extracts those latents from the sorted population.
Closed-loop replay tests whether decoded estimates can drive realtime triggers using the sorted-selected models.

Six computational operations are kept conceptually separate:
\begin{enumerate}[leftmargin=*]
  \item population partition (which units enter a model);
  \item observation construction (causal spike counts);
  \item manifold geometry (map to latents $z_t$);
  \item temporal dynamics on the manifold (history of length $L$);
  \item behavioral decoding ($\hat y_{t+\tau}$);
  \item inter-region coupling (trisynaptic / EC feedforward; Section~\ref{sec:interregion}).
\end{enumerate}

\section{Public software workflow}
% ============================================================

The intended user interface consists of three scripts:
\begin{enumerate}[leftmargin=*]
  \item \texttt{run\_simulation.py} --- generate behavior, rates, spikes, recording, sorting;
  \item \texttt{run\_decoder.py} --- compare models/windows, select the best configuration, run closed-loop replay, optionally plot (calls \texttt{run\_full\_decoder\_workflow});
  \item \texttt{run\_visualizations.py} --- regenerate figures from saved outputs only (never retrains).
\end{enumerate}

\begin{lstlisting}[language=bash,caption={Standard end-to-end commands (sorted-only deployment selection).}]
python run_simulation.py \
    --output outputs/ratinabox_004 \
    --seed 4

# Default: sorted spikes only; full causal-window grid; deployable registry
python run_decoder.py \
    --input outputs/ratinabox_004 \
    --output outputs/ratinabox_004 \
    --closed-loop-target spatial_context \
    --selection-policy shortest_near_optimal \
    --compile-pdf

# Optional oracle GT diagnostics (still selects deployable models from sorted):
#   --include-ground-truth-diagnostics

python run_visualizations.py \
    --experiment outputs/ratinabox_004 \
    --all --compile-pdf
\end{lstlisting}

Hyperparameter tuning is intentionally \emph{internal} to the decoder workflow: users need not manually choose a single global $W$ or call separate comparison/replay scripts for the standard path.
The update interval is fixed at $20\,\mathrm{Hz}$ / $50\,\mathrm{ms}$; the causal window $W$ is selected \emph{independently per target}.

\section{Simulation pipeline}
% ============================================================

Default session duration is $600\,\mathrm{s}$ (10 minutes). Behavior and rate updates run at $20\,\mathrm{Hz}$ ($\Delta t = 0.050\,\mathrm{s}$).

\begin{enumerate}[leftmargin=*]
  \item \textbf{Behavior:} RatInABox open-field trajectory (thigmotaxis, stalls, smooth turns).
  \item \textbf{Rates:} RatInABox neuron classes with anatomical mapping and hippocampal dynamics overlays (Sections~\ref{sec:riab-pops}--\ref{sec:interregion}).
  \item \textbf{Spikes:} inhomogeneous Poisson sampling (ground truth).
  \item \textbf{Recording:} multi-channel templates, noise, motion amplitude drift, collisions.
  \item \textbf{Sorting:} Kilosort-like re-extraction with misses, jitter, contamination.
\end{enumerate}

Primary simulation outputs: \texttt{behavior.csv}, \texttt{units.csv}, \texttt{spikes\_ground\_truth.csv}, \texttt{spikes\_sorted.csv}, \texttt{anatomy\_regions.csv}, \texttt{summary.json}, \texttt{ratinabox\_group\_metadata.csv}, \texttt{rates.npy}, and \texttt{neural\_backend\_metadata.json}.

\subsection{Cell type $\leftrightarrow$ probe contact}
For the RiaB backend, each unit is assigned a probe channel from the depth band matching its cell type via \texttt{CELL\_TYPE\_TO\_PROBE} in \texttt{hippo\_sim/anatomy.py}:
\begin{equation}
  (\mathrm{region},\,\mathrm{layer})
  =
  \begin{cases}
    (\mathrm{CA1},\,\mathrm{oriens}) & \mathrm{CA1\_int}, \\
    (\mathrm{CA1},\,\mathrm{pyramidal}) & \mathrm{CA1\_pyr}, \\
    (\mathrm{CA2},\,\mathrm{pyramidal}) & \mathrm{CA2\_pyr}, \\
    (\mathrm{CA3},\,\mathrm{pyramidal}) & \mathrm{CA3\_pyr}, \\
    (\mathrm{DG},\,\mathrm{granule}) & \mathrm{DG\_granule}, \\
    (\mathrm{Subiculum},\,\mathrm{pyramidal}) & \mathrm{Sub\_bvc}, \\
    (\mathrm{MEC},\,\mathrm{layer2}) & \mathrm{MEC\_grid},\,\mathrm{MEC\_speed}, \\
    (\mathrm{MEC},\,\mathrm{layer3}) & \mathrm{MEC\_hd}.
  \end{cases}
  \label{eq:probe-contact}
\end{equation}
Channel $c$ is drawn uniformly from sites with depth $z\in[z_{\mathrm{start}},z_{\mathrm{end}})$; depth is $z=c\cdot 20\,\mu\mathrm{m}$.
Layer matching is preferred; if the exact layer pool is empty, any segment of the same region is used as fallback.

\textbf{Caveat:} MEC/subiculum bands are co-recorded afferent populations for decoding and manifold analysis.
This is \emph{not} a claim that a single Neuropixels shank spans all of these structures in vivo; it is a contact-assignment convenience so afferent cell types land on distinct depth bands rather than polluting CA depths.

\section{Hippocampal dynamics overlays}
\label{sec:dynamics}
% ============================================================

Let $R^{\mathrm{RiaB}}_{i}(t)$ be the raw RatInABox (or fallback) rate for unit $i$ of cell type $c$ in population group $G$ (\textbf{Stage A}).
When \texttt{apply\_hippocampal\_dynamics=True} (default), the backend applies the overlays below (\textbf{Stage B}; implemented in \texttt{apply\_hippocampal\_dynamics}).
\textbf{Stage C} (trisynaptic / EC feedforward) is Section~\ref{sec:interregion}.

\subsection{Shared global features}
From the same behavioral trajectory, global features include theta phase $\phi_\theta(t)$, ripple envelope $r(t)\in[0,1]$, and speed $v(t)$.
These are shared across regions (common clock / state), then weighted per cell type.

\subsection{Per-group overlays}
With cell-type parameters from Table~\ref{tab:rate-params} / \ref{tab:rate-params-afferent},
\begin{align}
  R_i &\leftarrow R_i^{\mathrm{RiaB}}, \\
  R_i &\leftarrow R_i\,(1 + w_c^{\theta}\cos\phi_\theta(t))
    && \text{if group enables theta}, \label{eq:dyn-theta}\\
  R_i &\leftarrow R_i\,(1 + w_c^{\mathrm{speed}} f^{\mathrm{speed}}(t))
    && \text{if speed gain}, \label{eq:dyn-speed}\\
  R_i &\leftarrow R_i + w_c^{\mathrm{ripple}} A_c\, r(t)
    && \text{if ripple}, \label{eq:dyn-ripple}\\
  R_i &\leftarrow
    \begin{cases}
      0.1\,b_c & \text{if } R_i / \max_t R_i < \theta_c^{\mathrm{sparse}}, \\
      R_i & \text{otherwise}
    \end{cases}
    && \text{if DG sparsity}, \label{eq:dyn-sparse}\\
  R_i &\leftarrow R_i + w_c^{\mathrm{rec}}\,\overline{R}_{G}(t)
    && \text{if CA3 recurrent}, \label{eq:dyn-rec}
\end{align}
where $\overline{R}_{G}(t)=\frac{1}{|G|}\sum_{j\in G} R_j(t)$ is the within-group population mean (CA3 autoassociative sketch).
CA1 phase-precessing place cells skip the multiplicative theta overlay because phase precession is already built into the RiaB contrib class.
Rates are finally clipped: $R_i\leftarrow\max(R_i,0)$.

\subsection{Interneuron equation}
Synthetic interneurons are not a RiaB class (region comes from probe placement).
With baseline $b_{\mathrm{int}}$, anti-CA1 weight $w_{\mathrm{anti}}$ (default $0.35$), and normalized CA1 pyramidal population mean
$\tilde R_{\mathrm{CA1}}(t)=\overline{R}_{\mathrm{CA1}}(t)/\max_t\overline{R}_{\mathrm{CA1}}$,
\begin{equation}
  R_i^{\mathrm{int}}(t)
  =
  g_i\, b_{\mathrm{int}}
  \bigl(1 + w_{\mathrm{int}}^{\theta}\cos(2\pi f_\theta t)\bigr)
  \bigl(1 - w_{\mathrm{anti}}\,\tilde R_{\mathrm{CA1}}(t)\bigr)
  +
  w_{\mathrm{int}}^{\mathrm{ripple}} A_{\mathrm{int}}\, r(t),
  \label{eq:ca1-int}
\end{equation}
with per-unit gain $g_i\sim\mathrm{Unif}(0.8,1.2)$.
This is explicit \emph{cross-population} coupling: interneurons are anti-correlated with CA1 pyramids and later inhibit CA1 via Eq.~\ref{eq:ff-int}.

% ============================================================
\section{Inter-region coupling (trisynaptic / entorhinal feedforward)}
\label{sec:interregion}
% ============================================================

After Stage~B local overlays, Hippo applies a directed rate coupling that sketches the classic trisynaptic loop, direct EC$\to$CA1, CA2 collateral drive, and interneuron feedback onto CA1.
Implementation: \texttt{hippo\_sim/feedforward.py}, invoked from \texttt{ratinabox\_neural\_backend.py}.
Disable with \texttt{apply\_feedforward=false} (or \texttt{feedforward.enabled=false}).

\subsection{Region means}
Let $A$ index circuit nodes and $G_A$ the set of simulated units assigned to that node
($A\in\{\mathrm{MEC},\mathrm{DG},\mathrm{CA3},\mathrm{CA2},\mathrm{CA1},\mathrm{INT},\mathrm{SUB}\}$):
\begin{equation}
  \overline{R}_{A}(t)
  =
  \frac{1}{|G_A|}\sum_{i\in G_A} R_i(t).
  \label{eq:region-mean}
\end{equation}
MEC pools \texttt{MEC\_grid}, \texttt{MEC\_hd}, and \texttt{MEC\_speed}.
By default upstream means are peak-normalized,
\begin{equation}
  \tilde R_A(t)=\overline{R}_A(t)/\max_{t'}\overline{R}_A(t'),
  \label{eq:region-norm}
\end{equation}
so synaptic weights $w$ are dimensionless gains on a unit-scale drive
(set \texttt{normalize\_upstream=false} to drive in raw Hz).

\subsection{Excitatory feedforward (applied first)}
\begin{align}
  R_i^{\mathrm{DG}}(t)
  &\leftarrow
  R_i^{\mathrm{DG}}(t)
  + w_{\mathrm{MEC}\to\mathrm{DG}}\,\tilde R_{\mathrm{MEC}}(t),
  \label{eq:ff-dg}\\
  R_i^{\mathrm{CA3}}(t)
  &\leftarrow
  R_i^{\mathrm{CA3}}(t)
  + w_{\mathrm{DG}\to\mathrm{CA3}}\,\tilde R_{\mathrm{DG}}(t),
  \label{eq:ff-ca3}\\
  R_i^{\mathrm{CA2}}(t)
  &\leftarrow
  R_i^{\mathrm{CA2}}(t)
  + w_{\mathrm{MEC}\to\mathrm{CA2}}\,\tilde R_{\mathrm{MEC}}(t)
  + w_{\mathrm{CA3}\to\mathrm{CA2}}\,\tilde R_{\mathrm{CA3}}(t),
  \label{eq:ff-ca2}\\
  R_i^{\mathrm{CA1}}(t)
  &\leftarrow
  R_i^{\mathrm{CA1}}(t)
  + w_{\mathrm{CA3}\to\mathrm{CA1}}\,\tilde R_{\mathrm{CA3}}(t)
  + w_{\mathrm{MEC}\to\mathrm{CA1}}\,\tilde R_{\mathrm{MEC}}(t).
  \label{eq:ff-ca1}
\end{align}
CA3 autoassociative recurrence $w_{\mathrm{CA3}\to\mathrm{CA3}}$ is \emph{not} repeated here; it is already applied in Eq.~\ref{eq:dyn-rec}.
After each addition, rates are rectified: $R\leftarrow\max(R,0)$.

\subsection{Interneuron feedback (applied second)}
Synthetic interneurons are constructed from the \emph{post-feedforward} CA1 mean
(Eq.~\ref{eq:ca1-int}), then inhibit CA1 pyramids:
\begin{equation}
  R_i^{\mathrm{CA1}}(t)
  \leftarrow
  \max\bigl(
    R_i^{\mathrm{CA1}}(t)
    - w_{\mathrm{INT}\to\mathrm{CA1}}\,\tilde R_{\mathrm{INT}}(t),\,
    0
  \bigr).
  \label{eq:ff-int}
\end{equation}

\subsection{What this buys (and what it does not)}
With Eqs.~\ref{eq:ff-dg}--\ref{eq:ff-int} enabled, upstream region activity \emph{causally} modulates downstream rates on the same shank population used for decoding.
This is still a linear mean-field sketch (no axon delays, no synaptic depression/facilitation, no spike-timing dependent plasticity).
Subiculum BVCs are co-recorded but do not yet enter the feedforward graph (reserved for future Sub$\leftrightarrow$CA1 / MEC extensions).

\subsection{Decoder-facing consequence}
Region-PCA / cell-type partitions now observe populations that share directed drive, not only a common trajectory clock.
Closed-loop decoding still estimates information in the joint observation $x_t^{(W)}$, but ground-truth rates themselves embed trisynaptic structure.

\section{Causal decoding}
\label{sec:causal}
% ============================================================

\subsection{Observation model}
At each behavioral frame time $t$, the decoder builds a causal population count vector
\begin{equation}
  x_t^{(W)} \in \mathbb{R}^{N},
  \qquad
  \bigl(x_t^{(W)}\bigr)_i
  =
  \#\bigl\{\text{spikes of unit } i \text{ in } [t-W,\, t)\bigr\}.
  \label{eq:counts}
\end{equation}
The interval is half-open: spikes with time $\ge t$ are never included.
Optional rate features are $r_t^{(W)} = x_t^{(W)} / W$.

$z_t$ & --- & Current manifold coordinate \\
$L$ & optional & Latent history length (frames) \\
$\tau$ & $0$ (searchable) & Prediction lag for $\hat y_{t+\tau}$ \\
train fraction & 0.70 & Contiguous temporal split \\
\bottomrule
\end{tabular}
\end{table}

Default window grid (standard / full deployment selection):
\begin{equation}
  W \in \{0.050,\, 0.100,\, 0.250,\, 0.500,\, 1.000\}\,\mathrm{s}.
\end{equation}
Short $W$ lowers latency but yields fewer spikes; long $W$ improves count reliability at the cost of effective delay.
\textbf{Important:} $W{=}0.250\,\mathrm{s}$ is \emph{not} hard-coded as the selected window.
Each target independently scores every candidate $W$; a shared $250\,\mathrm{ms}$ result is allowed only if it wins empirically for that target.
If every target selects the same $W$, the workflow prints a warning and the full score table
\texttt{deployment\_decoder\_selection/all\_sorted\_window\_scores.csv} must be inspected.

\subsection{Architectural separation}
\begin{equation}
  x_t^{(W)}
  \;\longrightarrow\;
  z_t
  \;\longrightarrow\;
  Z_t^{(L)}=[z_{t-L+1},\ldots,z_t]
  \;\longrightarrow\;
  \hat y_{t+\tau}.
  \label{eq:arch}
\end{equation}
Here $W$ provides spike evidence for the \emph{current} state; $L$ models recent movement through the manifold; $\tau$ is a future prediction horizon.
These roles must not be collapsed into a single ``decoder memory'' parameter.

\section{Decoder model zoo}

Implemented in \texttt{realtime/decoder\_models.py}.

\subsection{Quick mode (default)}
\begin{itemize}[leftmargin=*]
  \item Regression: Ridge ($\alpha=1$), PCA-Ridge (95\% variance), Random Forest (100 trees, depth 12).
  \item Classification: Logistic Regression (balanced), Random Forest classifier (balanced).
  \item Bayesian place decoder when applicable (Section~\ref{sec:bayes}).
\end{itemize}

\subsection{Full mode}
Additionally includes Elastic Net ($\alpha=0.1$, $\ell_1$-ratio $0.5$), PLS (10 components), histogram gradient boosting, $k$-NN ($k=15$), linear SVM, and a causally smoothed Bayesian place decoder.

\subsection{Selection policies and deployment rule}
\label{sec:deployment-selection}
After evaluating all $(\mathrm{model},\,W,\,\mathrm{feature\_mode})$ combinations per target on \textbf{sorted} spikes:
\begin{description}[leftmargin=*]
  \item[\texttt{best\_accuracy}] pick the best primary metric;
  \item[\texttt{shortest\_near\_optimal}] (default) pick the shortest $W$ within 5\% of the best score
  ($\le 1.05\times$ best if lower-is-better; $\ge 0.95\times$ best if higher-is-better).
\end{description}

\paragraph{Deployment rule.}
Deployable models are written only to
\begin{itemize}[leftmargin=*]
  \item \texttt{models/best\_realtime\_decoders.json}
  \item \texttt{deployment\_decoder\_selection/best\_realtime\_decoders.json}
\end{itemize}
These registries contain sorted-spike selections only (per-target decoder, causal window, feature mode, artifact paths, $20\,\mathrm{Hz}$ update metadata).
Ground-truth comparisons, when requested with \texttt{--include-ground-truth-diagnostics}, are tagged \texttt{oracle / non-deployable} and never enter the realtime registry.
Closed-loop replay loads \texttt{models/best\_realtime\_decoders.json} and does not retrain when comparison artifacts already exist.
Offline-only manifolds (e.g.\ Isomap) may win offline accuracy tables but are not auto-deployed; realtime recommendations prefer realtime-compatible features (counts / PCA).

\section{Bayesian place decoder}
\label{sec:bayes}
% ============================================================

A Poisson likelihood place-map decoder on a $n_{\mathrm{bins}}\times n_{\mathrm{bins}}$ grid ($n_{\mathrm{bins}}=20$ by default).
Occupancy is floored at $10^{-3}$.
Optional causal posterior smoothing uses weight $\alpha=0.7$ on the previous posterior only (never future).
Schematically,
\begin{equation}
  \log P(\mathrm{bin}\mid x_t)
  \;\propto\;
  \log P(\mathrm{bin})
  +
  \sum_i
  \Bigl[
    x_{t,i}\log\lambda_i(\mathrm{bin})
    -
    \lambda_i(\mathrm{bin})\, W
  \Bigr].
\end{equation}
A derived-context variant maps the place posterior to categorical spatial / wall-distance labels.

\subsection{Optional temporal manifold decoding}
Enabled with \texttt{--enable-temporal-manifold}:
\begin{equation}
  x_t^{(W)}
  \to
  z_t
  \to
  Z_t^{(L)}=[z_{t-L+1},\ldots,z_t]
  \to
  \hat y_{t+\tau}.
\end{equation}
Defaults: representations $\{\texttt{raw},\texttt{pca}\}$ with $\sqrt{\mathrm{counts}}$ + standardization on the temporal PCA path; history lengths
$L\in\{1,2,5,10,20\}$ frames ($50\,\mathrm{ms}$--$1\,\mathrm{s}$ at $20\,\mathrm{Hz}$);
models \texttt{raw\_static}, \texttt{static\_latent}, \texttt{flattened\_history};
controls: averaged and time-shuffled histories.
Selection uses contiguous train/validation/test splits with a leakage gap; validation only is used for model selection.
Planned extensions: causal GRU/TCN, autoencoders, CEBRA.

\subsection{Offline Isomap and realtime distillation}
\texttt{IsomapManifoldEncoder} (\texttt{realtime/manifolds/isomap.py}) embeds $\sqrt{\mathrm{counts}}$ (optionally after PCA) with geodesic nearest-neighbor distances.
It is registered as \texttt{isomap} / static mode \texttt{global\_isomap} for offline comparison and diagnostics, with \texttt{realtime\_compatible=false}.
Nonlinear decoder heads (e.g.\ RBF-SVR/SVC, MLP) may be evaluated offline against Isomap features; deployable realtime defaults remain counts / PCA unless distillation passes.

\paragraph{Parametric approximation.}
Mode \texttt{global\_isomap\_distilled} fits classic Isomap on training counts, then trains a causal parametric map $E_\theta(x_t)\approx z_t^{\mathrm{Isomap}}$ (default Ridge).
It is realtime-eligible when per-transform latency $\le 50\,\mathrm{ms}$ and held-out Procrustes correlation $\ge 0.7$.
This is \emph{not} mathematically identical to Isomap.

\section{Future RatInABox behavior extensions}
% ============================================================

These notes record alignment with RatInABox and optional next steps for behavior generation.
They are intended as a pickup brief for later implementation; none of the items below are required for the current decoder baseline.

\subsection{Alignment with RatInABox}

Hippo is a hippocampal data-generation pipeline (RatInABox locomotion $\rightarrow$ rate/spike models $\rightarrow$ sorting degradation $\rightarrow$ TCN/decoder training) and falls under RatInABox use case~(i): generating realistic trajectories and/or neural data for downstream analysis and model training.
Behavior is currently RatInABox random open-field motion; the \texttt{ratinabox\_neurons} backend already syncs cell firing to a saved \texttt{BehaviorTrace} via \texttt{\_sync\_agent\_to\_behavior\_step}, so once a trajectory exists---random, imported, or RL-generated---place/grid/HD cells can follow it.
Only a behavior front-end (and optional RL loop) is missing.
The success criterion is decoder (and later TCN) performance at deployment.
Priority for that goal: match deployment data (especially real sorted spikes + that session's tracking) $\gg$ sorting/noise realism $\gg$ imported or RL trajectories.
Trajectory import and reward RL do \emph{not} fix remapping, cross-day unit drift, or sorting contamination.

\subsection{Real trajectory implementation (\texttt{import\_trajectory})}

RatInABox can drive cells from an imported path without the random motion model (\texttt{Agent.import\_trajectory(times, positions)}, or a \texttt{.npz} with keys \texttt{t}/\texttt{pos}, e.g.\ Sargolini for smoke tests).
Users still call \texttt{Agent.update(dt)}, which interpolates along the path and \emph{loops} if the run exceeds the imported duration.
In Hippo this means a new behavior path (load real $(t, xy)$) while leaving rates $\rightarrow$ spikes $\rightarrow$ sorting $\rightarrow$ \texttt{ManifoldDataset} / decoders unchanged.
Implementation pitfalls: keep arena scale consistent (meters in RatInABox, cm elsewhere); prefer \texttt{interpolate=False} for high-rate tracking; require solid boundaries; avoid short looping paths that bias training; imported/forced motion can illegally cross walls or leave the environment.
Distinguish two meanings of ``session trajectory'': (A)~import a path into the sim to drive \emph{synthetic} spikes---needs \texttt{import\_trajectory}; (B)~train on \emph{real} sorted spikes aligned to that session's tracking---standard alignment, no RatInABox import.
Worth doing eventually for sim$\rightarrow$real kinematic match (occupancy, speed/dwell, wall bias; especially for TCNs and speed/movement targets), but not the highest-leverage next step for decoder success.

\subsection{RL-based reward simulation}

Separately, RatInABox's model-free RL demo (paper Fig.~3e) uses continuous TD learning: a value neuron approximates
\begin{equation*}
  V^{\pi}(x)=\sum_i w_i F^{\mathrm{pc}}_i(x)
\end{equation*}
over place-cell features, then an improved policy sets $\mathrm{drift\_velocity} \propto \nabla V$ so the Agent biases toward high-value regions; iterating yields near-shortest paths to reward while avoiding walls.
Hippo could use contribs such as \texttt{ValueNeuron} and \texttt{TaskEnvironment} (plus \texttt{Agent.update(..., drift\_velocity=...)}) to synthesize goal-directed sessions instead of random forage---changing occupancy near reward, approach/leave speeds, and stereotyped routes.
Light reward stubs already exist (\texttt{reward\_zones} viz, \texttt{reward\_tuning\_strength} metadata) but are not an RL system.
This improves behavioral realism for reward-guided tasks and future reward-related labels, but only indirectly helps decoders; it does not train the spike-sorted TCN/decoder stack.
Treat as a behavior-model feature when deployment or science needs learned reward-seeking---not a general decoder boost.
Relative to import: \texttt{import\_trajectory} replays a fixed recorded policy; TD+drift synthesizes a learned policy toward reward.

\section{Limitations}
% ============================================================

\begin{itemize}[leftmargin=*]
  \item Simulated region functions and rate parameters are configurable hypotheses, not recovered biology.
  \item MEC/subiculum probe bands are co-recording conveniences for afferent cell types, not a claim about single-shank span in vivo.
  \item Feedforward coupling (Eqs.~\ref{eq:ff-dg}--\ref{eq:ff-int}) is a linear mean-field sketch: no axonal delays, short-term plasticity, or STDP.
  \item Subiculum BVCs are co-recorded but not yet wired into the feedforward graph.
  \item Sorted spikes lose some ground-truth metadata (identity, projections).
  \item Deployable selection is intentionally sorted-only; ground-truth metrics are oracle diagnostics and can overstate closed-loop performance.
  \item Supervised embeddings (when added) reflect supplied labels and should not be treated as complete intrinsic geometry.
  \item Realtime-compatible methods must not use future spikes or future smoothing.
  \item Simulation results require later experimental validation.
\end{itemize}
